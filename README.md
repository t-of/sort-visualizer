# 可視化ソート — 2 つの並べ替えで競走

ばらばらの棒を、2 つのやり方で同時に並べ替えて競走させる。データの並び方を変えると勝ち負けが入れ替わり、比べた回数・動かした回数も数字で分かる。（旧名 そろえっこ）

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/sort-visualizer/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 上と下に、同じばらばらの棒が並んでいる。それぞれ違うやり方で、低い順に並べ替える。
2. ▶ を押すと、両方が 1 手ずつ同時に進む。**少ない手数で先にそろったほうが勝ち**。
3. やり方の名前をタップして変えたり、「並び方」を変えたりしてみよう。「ほぼそろい」にすると、勝ち負けがひっくり返ることがある。

- 1 手 = 2 本の棒を比べる、または棒を動かす（入れ替える・置く）。手数 = 比べた + 動かした
- やり方（9 種）: バブル・カクテル・選択・挿入・シェル・コーム・マージ・クイック・ヒープ
- 並び方: でたらめ / ほぼそろい / 逆さま / 同じ高さ多め。本数: 16 / 40 / 100。速さ: 1 秒に 3 / 60 / 400 / 4,000 手
- 棒の色: 黒 = ふつう、オレンジ（下に三角）= 比べている、水色 = 動いた、ピンク = 注目、灰色 = 確定。薄い帯 = 今の範囲
- 「はじめから」は同じデータで 0 手に戻す。「新しいデータ」は別のばらばらにする
- 結果の「共有」の URL（`?a=insertion&b=quick&d=nearly&n=40&s=123456`）を開くと、同じレースが見られる
- PC: Space で再生・停止、→ で 1 手

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 9 種 × 4 つの並び方でそろう・1 手の決まり・種・保存・URL のテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `sort.js` | 画面に触らない中身。9 種のやり方（`function*` で 1 手ずつ出来事を出す）、レーンを 1 手進める仕組み、データと種、保存と URL の読み書き |
| `main.js` | 画面・操作・Canvas の描画 |
| `test.mjs` | `sort.js` のテスト |

保存するのは `localStorage` の `sort-visualizer.state` だけ（`{ v: 1, a, b, shape, size, speed, seenHelp }`）。データの種と途中の状態は保存しない。
